Program-11: Temperature Converter (Celsius ↔ Fahrenheit) in Docker

Objective:

Create a simple Python program that converts temperature values from Celsius to Fahrenheit and Fahrenheit to Celsius, and run it fully inside a Docker container without requiring internet.

Step 1: Create a Folder

mkdir TempConverter

cd TempConverter


Step 2: Create Python Program

nano Celsious.py

Python File: Celsious.py

def c_to_f(c):
    return (c * 9/5) + 32


def f_to_c(f):
    return (f - 32) * 5/9


if __name__ == "__main__":
    print("=== Temperature Converter (Docker Offline) ===")
    print("1. Celsius to Fahrenheit")
    print("2. Fahrenheit to Celsius")

    choice = input("Enter choice (1 or 2): ")

    if choice == "1":
        c = float(input("Enter Celsius: "))
        print("Fahrenheit =", c_to_f(c))

    elif choice == "2":
        f = float(input("Enter Fahrenheit: "))
        print("Celsius =", f_to_c(f))

    else:
        print("Invalid choice!")


Step 3: Create a Dockerfile

nano Dockerfile

Dockerfile:

FROM python:3.10-slim

WORKDIR /Celsious

COPY Celsious.py .

CMD ["python", "Celsious.py"]


Step 4: Build Docker Image

rit@rit:~/chart$ docker build -t celsious-convert .


Step 5: Run Docker Container

rit@rit:~/chart$ docker run -it celsious-convert


Output:

=== Temperature Converter (Docker Offline) ===

1. Celsius to Fahrenheit
2. Fahrenheit to Celsius

Enter choice (1 or 2): 1

Enter Celsius: 23

Fahrenheit = 73.4


Result:

Successfully created and executed a temperature converter program inside a Docker container.
