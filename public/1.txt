# Experiment 1: Create Docker Image – Hello World

## Objective

Create a simple Python program and run it inside a Docker container.

## Experiment-1: Create Docker Image

**Login:** RIT-ADMIN
**Password:** rit@2025

### Step 1: Create a folder Hello-world in Home folder

```bash
gedit app.py
```

Open Terminal:

```bash
cd hello-world
gedit app.py
```

#### 1. Create a simple Python program

Make a:

```python
print("Hello, World from Docker!")
```

### Step 2: Write a Dockerfile

Create a file named `Dockerfile` in the same folder:

```bash
gedit Dockerfile
```

```dockerfile
FROM python:3.10-slim
WORKDIR /app
COPY . /app
CMD ["python", "app.py"]
```

### Step 3: Build the Docker image

Open a terminal in the folder and run:

```bash
docker build -t hello-docker .
```

### Step 4: Run the container

Now run the image:

```bash
docker run hello-docker
```

**Output should be:**

```text
Hello, World from Docker!
```
