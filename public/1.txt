7. Ping Simulation

Python File: ping.py

import os
import sys

if len(sys.argv) != 2:
    print("Usage: python ping.py <hostname_or_ip>")
    sys.exit(1)

host = sys.argv[1]

response = os.system(f"ping -c 4 {host}")

if response == 0:
    print(f"{host} is reachable")
else:
    print(f"{host} is not reachable")


Dockerfile:

FROM python:3.10-slim

WORKDIR /ping

COPY ping.py .

CMD ["python", "ping.py"]


Execution Steps:

Step 1: Check network configuration

it@rit:~/ping$ ifconfig

Step 2: Execute the Python program

it@rit:~/ping$ python3 ping.py 127.0.0.1
