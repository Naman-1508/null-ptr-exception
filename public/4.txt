# Experiment 4: Container Program – Factorial Calculator

## Objective

* To create a Python program that calculates the factorial of a number.
* To dockerize the program and run it inside a container.

## Steps

### 1. Create Python Program (factorial.py)

```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

n = int(input("Enter a number: "))
result = factorial(n)
print("Factorial of", n, "is", result)
```

### 2. Create Dockerfile

```dockerfile
FROM python:3.10-slim
WORKDIR /factorial
COPY . /factorial
CMD ["python", "factorial.py"]
```

### 3. Build the Docker Image

```bash
docker build -t factorial-calculator .
```

### 4. Run the Container (Interactive Mode)

```bash
docker run -it factorial-calculator
```

### 5. Expected Outcome

When the container starts, it will prompt for input:

```text
Enter a number: 5
Factorial of 5 is 120
```

```text
rit@rit:~/hello$ docker run -it hello-docker
Enter a number: 5

```
