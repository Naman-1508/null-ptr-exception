Program-10: Simple Ubuntu Container with a Custom Script

Step 1: Create a Working Folder

rit@rit:~$ cd shell

rit@rit:~/shell$


Step 2: Create a Shell Script

rit@rit:~/shell$ nano hello.sh

Shell Script (hello.sh):

#!/bin/bash

echo "-----------------------------------------"
echo " Welcome to Docker Offline Demo!"
echo " This script is running inside a container."
echo "----------------------------------------------"


Step 3: Create a Dockerfile

rit@rit:~/shell$ nano Dockerfile

Dockerfile:

FROM ubuntu:latest

WORKDIR /app

COPY hello.sh .

# Give execute permission
RUN chmod +x hello.sh

# Run the script
CMD ["./hello.sh"]


Step 4: Create Docker Image

rit@rit:~/shell$ docker build -t shell-demo .


Step 5: Run Docker Container

rit@rit:~/shell$ docker run -it shell-demo


Output:

-----------------------------------------
 Welcome to Docker Offline Demo!
 This script is running inside a container.
----------------------------------------------


rit@rit:~/shell$


Result:

Successfully created and executed a custom shell script inside an Ubuntu Docker container.
