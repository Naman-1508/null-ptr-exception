# Experiment 6: Environment Variables Printer

## Objective

Print environment variables passed to container.

### Python File: env.py

```python id="p5e2j1"
import os

print("=== Environment Variables Passed to Container ===\n")

for key, value in os.environ.items():
    print(f"{key} = {value}")
```

### Dockerfile

```dockerfile id="q7m3vx"
FROM python:3.10-slim
WORKDIR /app
COPY env.py .
CMD ["python", "env.py"]
```

### Create Docker Image

```text id="k1n8sz"
rit@rit:~/Env$ docker build -t env-calculator .
```

### Run the Container

```text id="m4c6qa"
rit@rit:~/Env$ docker run -it env-calculator
```
